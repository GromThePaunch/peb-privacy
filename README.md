# Peb privacy policy

Public privacy policy for the Peb Android app. The official copy is
https://themadmadigan.net/peb/privacy ; this repo (GitHub Pages:
https://gromthepaunch.github.io/peb-privacy/) is a backup.

`index.html` must stay word-for-word identical to `public/privacypolicy.html` in the app repo (that's the copy
Health Connect shows in the app). Update both together and bump the effective date.
